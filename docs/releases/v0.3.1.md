RAM Disk Studio の初回公開リリースです。日本語 UI から ImDisk / awealloc の RAM ディスクを管理し、読み書きと使用容量を確認できます。バージョン 0.3.1 は初期開発段階のリリースです。

## ダウンロードと起動

**Assets の `RamDiskStudio-0.3.1-win-x64.zip` をダウンロードしてください。** ビルド済みの `RamDiskStudio.exe`、必要な DLL、.NET ランタイムを同梱しています。`Source code (zip)` はソースコードです。

1. ZIP をローカルのフォルダーへすべて展開します。EXE と同じフォルダーのファイルも必要です。
2. [ImDisk Virtual Disk Driver](https://www.ltr-data.se/opencode.html/#ImDisk) を別途インストールします。物理メモリ固定を使う場合は awealloc も必要です。
3. 展開した `RamDiskStudio.exe` を起動します。ディスクの作成・解除と読み書き監視には、アプリ内の「管理者として再起動」を使います。

対象は **Windows x64** です。.NET の別途インストールは不要です。ImDisk / awealloc ドライバーは同梱していません。

## Added

- RAM ディスクの容量・ドライブ文字・NTFS / exFAT / FAT32 の指定、複数設定の保存、作成・解除。
- ImDisk の標準メモリと awealloc の物理メモリ固定、空き RAM の確認、アプリ起動時の自動作成。
- 読み書き速度・量・回数・IOPS・平均アクセスサイズ・使用容量・使用率のグラフ。
- 毎秒・毎分・毎時・毎日の履歴と、再起動後も継続する累計。
- マウスでの拡縮・移動・期間選択、0 対応の対数表示、変化を強調する縦軸、連動する比較グラフ。
- ライト / ダークモードとテーマの保存。
- デバイス識別情報の照合、強制解除時の追加確認、設定ファイルのバックアップ。

公開前の変更は、この初回リリースの追加機能としてまとめています。[Changelog 全文](https://github.com/lighfu/RamDiskStudio/blob/v0.3.1/CHANGELOG.md)

## データと既知の制約

- **RAM ディスク内のデータは、ディスクの解除・Windows の再起動・電源断で失われます。** アプリを終了するだけなら作成済みのディスクは残ります。
- イメージ保存・復元、Windows 起動時の自動作成、ファイル削除に合わせた動的メモリ解放には未対応です。アプリ起動時の自動作成は空のディスクを用意します。
- グラフは、キャッシュを含むファイル I/O の要求量の観測値です。物理メモリ帯域や成功した読み書き量を保証する測定ではありません。イベントの遅延・欠落があり得ます。
- 監視開始前から開いているファイルは、対象アプリで開き直してください。アプリ終了中・スリープ中のアクセスは記録しません。管理者権限がない場合は容量のみ記録します。
- 検証環境では通常解除のボリュームロックが拒否されました。通常解除が失敗した場合だけ強制解除を確認します。必要なデータを先に別ドライブへ保存してください。

## ファイルの確認

`SHA256SUMS.txt` を同じリリースから取得し、PowerShell で ZIP のハッシュを照合できます。

```powershell
Get-FileHash .\RamDiskStudio-0.3.1-win-x64.zip -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

同梱する依存ソフトウェアの表示は `THIRD-PARTY-NOTICES.md` と `licenses/`、ビルド情報は `BUILD-INFO.json` にあります。アプリの Authenticode コード署名は付けていません。
