RAM Disk Studio 0.4.0 では、画面を Material 3 Expressive に切り替え、ディスク管理・監視・自動起動を Rust に移行しました。旧版のディスク設定、表示テーマ、SQLite の監視履歴を引き続き利用できます。

## ダウンロード

Assets の **`RamDiskStudio-0.4.0-win-x64.zip`** を展開し、`RamDiskStudio.exe` を起動してください。ImDisk は別途インストールしてください。物理メモリ固定を使う場合は awealloc も必要です。ZIP の SHA-256 は `SHA256SUMS.txt` で確認できます。

## Added

- Windows ログオン時に、対象の RAM ディスクを自動作成する設定を追加しました。
- 自動起動の有効化・無効化・登録更新と、スタートメニューからの起動に対応しました。
- RAM Disk Studio 専用のアイコンを追加しました。

## Changed

- UI を m3e SDK 1.0.1 で再実装し、画面の案内を簡潔にしました。
- 左サイドバーの操作ボタンを上部に移し、一覧とモニターにウィンドウ幅を使えるようにしました。
- Windows x64 向けのネイティブ EXE を同梱しています。.NET ランタイムのインストールは不要です。

## Fixed

- 自動作成で 1 台が失敗しても、ほかの対象ディスクの処理を続けます。稼働中の所有ディスクは再作成せず、使用中のドライブ文字も上書きしません。

旧版で自動起動を設定済みの場合は、Rust 版の「自動起動」で「登録を更新」を選んでください。RAM ディスクのデータは解除・再起動・電源断で消えます。

Windows x64 で4件のテスト、画面の起動とグラフ操作、自動起動タスクの更新と登録後の通常起動を確認しました。実ドライブの作成・解除、ETW の実測、再ログオンは Rust 版では未検証です。[検証記録](https://github.com/lighfu/RamDiskStudio/blob/v0.4.0/docs/validation.md)
