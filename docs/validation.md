# 検証記録

## 検証環境

2026-09-13～2026-09-15 に、Windows x64（OS ビルド 26200）と .NET 10 で検証しました。

- ImDisk CLI: 2.1.2.50
- awealloc: 1.2.29.95
- バージョン 0.3.1: Release ビルドで警告・エラー 0、WPF UI 検証を含む **36/36 テスト成功**

この記録は機能検証です。ストレージ性能の比較ベンチマークではありません。

## 自動テスト

設定の保存・復元、入力検証、ドライブ所有権、作成・解除の制御、SQLite 履歴の永続化・集計・保存期間、グラフ操作、ライト / ダークのテーマ保存を検証しています。

WPF UI 検証では、実際の画面を描画し、設定入力、時間軸の拡縮・移動・期間選択、比較グラフの連動、縦軸固定、対数の 0 と欠測の区別、テーマ切り替え、確認ダイアログの返却値を確認しました。非同期の履歴読み込み中に表示条件を変えても、最新の条件だけを反映します。

最小ウィンドウ 1100×800、比較グラフ非表示、サイドバー非表示も確認しています。両テーマの通常文字・補助文字・凡例・アクセントボタン・情報表示・エラー文字は、対象背景に対して 4.5:1 以上のコントラストを検証しました。

通常のテストと UI 検証は、独立したテスト用設定・履歴と偽のディスク基盤を使います。実アプリの起動処理や実ドライブの作成は実行しません。

## ドライバーの統合テスト

管理者権限で、テスト専用の空いているドライブ文字を使用しました。

| メモリ方式 | ファイルシステム | 容量 | 結果 |
|---|---|---:|---|
| 標準メモリ（VM） | NTFS / exFAT | 各 64 MiB | 作成、形式確認、データ往復、設定再読込、解除を確認 |
| 標準メモリ（VM） | FAT32 | 256 MiB | 同上 |
| 物理メモリ固定（awealloc） | NTFS / exFAT | 各 64 MiB | 同上。ImDisk の照会結果が Physical Memory と示すことを確認 |
| 物理メモリ固定（awealloc） | FAT32 | 256 MiB | 同上 |

**検証環境では、通常解除のボリュームロックは拒否されました。** 通常解除の成功を検証済みとは扱いません。テスト専用ドライブは識別情報を再確認したうえで強制解除しました。製品では通常解除が失敗したときだけ追加確認を表示し、「いいえ」を初期選択にしています。

物理メモリ方式の統合・監視テストは、バージョン 0.2.1 時点で **30/30 成功**。以後の 0.3.0 / 0.3.1 はグラフとテーマを中心とする更新で、この実ドライブ統合テストは再実行していません。

## 監視・履歴

- 標準メモリと物理メモリ固定の NTFS ドライブで、既知のファイル読み書きを ETW で観測。
- 物理メモリ固定のテストでは、読み取り・書き込み各 13,631,488 bytes / 13 回以上の観測、容量記録、履歴 DB の再オープンを確認。
- 秒・分・時・日の集計、UTC の区切り、観測時間による平均、保存期間経過後の累計保持を確認。
- アプリの通常終了と更新後に、設定・記録開始日時・累計の保持、監視の再開、DB の整合性検査を確認。

監視開始前から開かれているファイルは、開き直してから集計できることを確認しました。表示値はキャッシュを含むファイル I/O 要求の観測値です。成功したバイト数、メモリマップ経由の CPU アクセス、物理メモリ帯域を表すものではありません。
